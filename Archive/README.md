# Archive/ — 归档中心

这里存放 **已完成使命或不再适用** 的历史文档。

## 放什么

- 被新方案替代的旧设计。
- 已被 Release 完全吸收的 Draft。
- 已经放弃 / 搁置的想法。
- 阶段性完成、不再需要日常参考的内容。
- 早期对话、原始材料、废弃方案和只在追溯时需要的证据。

## 原则

- **不删除**，保留下来用于追溯「当初为什么这么决定 / 为什么放弃」。
- 日常执行 **以 `Releases/` 为准**，不要照着 `Archive/` 里的内容做事。
- 从 `Releases/` 移入归档时，记得在 `Releases/` 的新文档里写明替代 / 迁移关系。
- 从 `Drafts/` 移入归档时，如仍有未来可复用的零散灵感，应先摘入 `Drafts/00_灵感索引.md`。
- 归档程序或可运行原型时应整体移动其目录，保持一个程序一个目录，不要把源码重新平铺。

## 给 AI agent 的提醒

`Archive/` 只作历史回溯，**不要据此执行**当前工作。默认不要读取 `Archive/`；只有用户明确要求、`Releases/` 来源关系指向、`Drafts/00_灵感索引.md` 指向，或确有追溯需要时才读。
